# Personal Developer Portfolio ⚡

> **Interactive terminal-themed developer portfolio and showcase.**  
> Live preview: **[luckeris.github.io/portfolio](https://luckeris.github.io/portfolio)**

---

## Overview

A lightweight, zero-framework developer portfolio built with modern vanilla web technologies. Features an interactive Unix-style terminal prompt, dynamic GitHub project showcase with automatic fallbacks, and dark/light theme switching.

### Features
* **Interactive Terminal**: Custom command simulator (`about`, `projects`, `contact`, `theme`, `clear`, `help`) with touch-friendly quick action chips on mobile.
* **Resilient Project Showcase**: Dynamically fetches latest repositories via GitHub API with automatic fallback to curated project cards during rate limits or network issues.
* **Responsive Design**: Fluid typography, dynamic viewport sizing (`100dvh`), and natural touch scrolling on mobile screens.
* **Modern Theming**: Dark and light modes utilizing OKLCH color palettes and CSS custom properties.
* **Zero Dependencies**: Pure HTML5, CSS3, and modern vanilla JavaScript without external frameworks or build steps.

---

## Tech Stack
* **Markup**: HTML5
* **Styling**: CSS3 (Grid, Flexbox, OKLCH color space, glassmorphism)
* **Scripting**: Vanilla JavaScript (ES6+, DOM APIs, IntersectionObserver)
* **Hosting**: GitHub Pages
